AI image workflow

AI portraits: improve the image without losing the person.

When a real person or reference image matters, visual quality is secondary to preserving the details that make the reference recognizable.

Where this job fails

Identity, facial structure, hair, skin tone, accessories and body proportions need explicit preservation checks after every revision.

Reference-faithful portrait prompt

Create a photorealistic portrait using the provided reference. Preserve the person's identity, facial structure, eyes, nose, mouth, jawline, natural skin tone and texture, hair, body proportions, clothing and accessories. Change only [REQUESTED CHANGE]. Keep lighting realistic and avoid beauty-filter effects, face reshaping, de-aging, invented accessories or changes to expression unless explicitly requested. After generation, compare the output side-by-side with the reference before accepting it.

Use a decision loop, not prompt roulette

1 · DefineFreeze the requirement

Write down what may change and what must remain exact.

2 · ChooseMatch the tool to the job

Use Prompt Lab to compare editorial fit and tradeoffs.

3 · GenerateRun a controlled prompt

Change one important variable at a time so revisions remain interpretable.

4 · VerifyInspect the misses

Check fidelity, text, anatomy, materials and constraints before publishing.
