Practical guide

Use AI to build the story before it builds the slides.

The fastest way to get a bad AI presentation is to ask for “10 slides about X.” Start with audience, decision and evidence first.

A better sequence

01Define the audience

What do they already know, and what decision should the deck support?

02Write the one-sentence takeaway

If the audience remembers one idea tomorrow, what should it be?

03Build the narrative

Context → problem → evidence → options → recommendation → next step.

04Assign one message per slide

Use the headline to state the conclusion, not merely name the topic.

05Add visuals after logic

Charts, diagrams and images should prove or clarify the slide message.

Prompt

Turn the source material below into a presentation for [AUDIENCE]. Goal: help the audience decide [DECISION]. First produce: 1. one-sentence takeaway, 2. 6–10 slide narrative, 3. one conclusion-style headline per slide, 4. evidence needed for each slide, 5. best visual form: chart, diagram, table, image or none. Do not invent statistics. Do not add slides that do not advance the decision. SOURCE: [PASTE MATERIAL]
