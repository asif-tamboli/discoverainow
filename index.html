AI agents

Useful when the work has steps.

Agents make the most sense when a task involves gathering information, making decisions, taking actions, and repeating the process over time.

Field note / 01

Don’t start with “I need an agent.”

Start with the recurring job. Define the inputs, decisions, actions, and what a good result looks like.

Example: “Every morning, scan customer feedback, group recurring issues, and flag anything urgent.”
